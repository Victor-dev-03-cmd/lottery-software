1. DASHBOARD
   View key: "dashboard"
   File: src/components/Dashboard.tsx (AgentDashboard)
================================================================================

PURPOSE
-------
Main overview screen. Shows the business health at a glance for a selected
time period — revenue, tickets, cash collected, outstanding balance, collection
rate, top agents, recent invoices, and supplier dues.

INPUTS
------
- Period Selector Pills  : "7D" / "30D" / "All"
                           Switches the date window used for all KPI metrics
                           and chart data.
- Agent Search Box       : Text input. Filters the agent summary table in
                           real-time by agent name.

BUTTONS
-------
- Refresh                : Reloads all dashboard data (KPIs, charts, tables)
                           from the local SQLite database.
- "7D" / "30D" / "All"  : Period pills. Changes the active period; all data
                           recalculates automatically.
- Export CSV             : Opens a native Tauri save-file dialog. Writes the
                           current dashboard snapshot (stats, agent summary,
                           recent invoices) to a .csv file.
- "+ New Invoice"        : Navigates to the New Invoice page.
- Agent Row (click)      : Navigates to the agent's detail / ledger view.

DATA DISPLAYED
--------------
- 5 KPI cards: Total Revenue (Rs.), Tickets Distributed (count), Cash
  Collected (Rs.), Outstanding Balance (Rs.), Invoice Count — all for the
  selected period.
- Collection Rate % — cash collected as % of invoiced amount.
- Nimalsiri Dues card: total unpaid balance owed to the supplier.
- Revenue Trend chart: daily bar/area chart of invoice totals.
- Agent Performance table: top 7 agents with name, invoiced, collected,
  outstanding, collection rate %.
- Agent Summary table: all agents — tickets, total value, winnings, cash paid,
  loan amount, outstanding balance. Filterable by search.
- Recent Invoices list: last 6 invoices with number, agent, date, amount,
  status badge.
- Supplier Aging: payment aging brackets showing overdue purchases by period.

2. ALERTS & REMINDERS
   View key: "alerts"
   File: src/components/Alerts.tsx
================================================================================

PURPOSE
-------
Monitors overdue agent payments and generates WhatsApp reminder messages in
English, Sinhala, or Tamil. Also shows low-stock inventory warnings and
supplier aging information.

INPUTS
------
- Language Selector      : Pills — "EN" / "සිංහල" / "தமிழ்".
                           Controls the language of generated reminder messages.
- Section Filter         : Pills — "All" / "Agents" / "Stock".
                           Scrolls/filters which section is visible.

BUTTONS
-------
- Refresh                : Reloads overdue agents, inventory stock, and
                           supplier aging data.
- "Send WhatsApp"        : (per agent) Opens the WhatsApp app / deep-link with
                           a pre-formatted reminder message in the selected
                           language.
- "Copy"                 : (per agent) Copies the reminder message text to the
                           clipboard so it can be pasted anywhere.
- "Batch Send"           : Loops through every agent with overdue balance older
                           than 7 days, opening WhatsApp one by one.
- Expand/Collapse (▶)    : (per agent card) Shows or hides the per-invoice
                           breakdown for that agent.

DATA DISPLAYED
--------------
- Summary bar: Total Alert Outstanding (Rs.), Critical (>60 days) count,
  Low Stock items count, Supplier owed (Rs.).
- Agent Alert Cards: sorted by days overdue, colour-coded badges —
  Current (green) / Overdue (amber) / High Risk (orange) / Critical (red).
  Each card shows agent name, total outstanding, most overdue invoice.
  Expanded: per-invoice table with invoice #, outstanding, days old, urgency.
- Low Stock Section: game name, remaining qty, threshold, warning icon.
- Supplier Aging Section: aging brackets (0-30d / 31-60d / 61-90d / 90+d)
  with invoice count and total outstanding per bracket.

3. NEW INVOICE / EDIT INVOICE
   View key: "new-invoice" / "edit-invoice"
   File: src/components/NewInvoice.tsx
================================================================================

PURPOSE
-------
Creates a new delivery invoice or edits an existing draft/waiting invoice.
Automatically fills the agent's previous outstanding balance, calculates
line item values with optional discounts, and supports barcode auto-calculation
(start + qty → end, or start + end → qty).

INPUTS — INVOICE HEADER
-----------------------
- Invoice Number         : Text. Auto-generated (e.g., INV-2025-0043). Editable.
- Invoice Date           : Date picker. Defaults to today.
- Agent                  : Dropdown. Selecting an agent auto-fills the
                           "Previous Outstanding" balance.
- Prepared By            : Text. Default value from settings.
- Delivery Route         : Text. Free-form route name.
- Sales Rep              : Text. Sales representative name.
- Cash Received          : Number. Cash collected at time of delivery.
- DLB Winning (Rs.)      : Number. DLB winning ticket credit applied.
- NLB Winning (Rs.)      : Number. NLB winning ticket credit applied.

INPUTS — LINE ITEMS (per row)
-----------------------------
- Ticket Name            : Text with datalist. Selecting a known game name
                           auto-fills the Unit Price from LotteryGames.
- Barcode Start          : Text. Entering start + qty auto-calculates end.
- Barcode End            : Text. Entering start + end auto-calculates qty.
- Qty                    : Number. Entering start + qty auto-calculates end.
- Unit Price             : Number. Auto-filled from game; editable.
- Discount %             : Number. Percentage discount applied to the line.
- Discount Amt (Rs.)     : Number. Fixed Rs. discount (alternative to %).

BUTTONS
-------
- "Add Row"              : Appends a new empty line item row.
- Trash icon (per row)   : Removes that line item.
- Eye / EyeOff icon      : Toggles the live A4 invoice preview panel on the
                           right side.
- "Save Draft"           : Saves the invoice with status "draft" and navigates
                           to the Draft Invoices page.
- "Confirm"              : Saves the invoice with status "waiting" (awaiting
                           confirmation) and navigates to Confirmed Invoices.
- "Print"                : Saves the invoice and navigates to the Print view.

DATA DISPLAYED
--------------
- Credit warning banner: appears if agent outstanding + new invoice > 90% of
  their credit limit.
- Commission preview: shows the expected commission amount based on active
  scheme for the selected agent.
- Invoice totals strip at the bottom:
    Invoice Total | Discount Total | Prev Outstanding | Total Payable
    Total Paid (Cash + Winnings) | Outstanding Balance
- Live A4 preview panel (right side, toggled): renders the invoice in real-time
  as you type, using the saved invoice template settings.

4. DRAFT INVOICES
   View key: "draft-invoices"
   File: src/components/DraftInvoices.tsx
================================================================================

PURPOSE
-------
Split-panel view for managing invoices in "draft" status. Left panel is a
searchable list; right panel shows a full A4 preview of the selected invoice.
Draft invoices do NOT count toward any agent's outstanding balance.

INPUTS
------
- Search Box             : Text. Filters the list by invoice number or agent
                           name in real-time.

BUTTONS
-------
- Refresh                : Reloads the list of draft invoices.
- Edit (Pencil icon)     : (per invoice, on hover/select) Navigates to the
                           Edit Invoice page for that draft.
- Confirm (✓)            : (per invoice) Moves the invoice from "draft" to
                           "waiting" status. Removes it from this list.
- Cancel (✗)             : (per invoice) Cancels the invoice (moves it to the
                           Cancelled Invoices page).
- Confirm Invoice (top bar) : Same as above — confirms the currently previewed
                              invoice.
- Cancel Invoice (top bar)  : Same as above — cancels the currently previewed
                              invoice.
- Edit Invoice (top bar)    : Same as above — navigates to edit.
- Edit Invoice (bottom bar) : Duplicate of top bar for convenience after
                              scrolling down through a long invoice.

DATA DISPLAYED
--------------
- Left panel: list of draft invoices — invoice #, agent name, date, invoice
  total (Rs.), "Draft" status badge.
- Count badge: number of draft invoices.
- Right panel (when an invoice is selected):
  - Sticky top action bar: status badge, Edit / Confirm / Cancel buttons.
  - Full A4 invoice preview: company header, logo, Bill To section, line items
    table, totals, signature lines.
  - Sticky bottom action bar: duplicate of top bar for long invoices.

8. INVOICE MODEL (TEMPLATE DESIGNER)

   File: src/components/InvoiceModel.tsx
================================================================================

PURPOSE
-------
Visual designer for the invoice print template. Customise branding colours,
upload a company logo, control which fields appear on the invoice, edit footer
text, or supply a fully custom HTML/CSS layout. A live A4 preview on the right
updates instantly as you make changes.

INPUTS — COLOR THEME SECTION
-----------------------------
- Primary Color          : Colour picker + hex text input. Controls header bar,
                           table header background, invoice number colour, and
                           accent lines.
- Accent / Text Color    : Colour picker + hex text input. Controls agent name
                           and secondary text colour.
- Preset Buttons (6)     : One-click presets — Red/Black, Navy/Gold,
                           Forest/Dark, Violet/Gray, Teal/Slate, Rose/Dark.
                           Sets both primary and accent at once.

INPUTS — COMPANY LOGO SECTION
------------------------------
- Upload Logo button     : File picker (PNG, JPG, SVG). Converts the selected
                           image to base64 and shows it in the preview.

INPUTS — INVOICE FIELDS SECTION
---------------------------------
- Show Barcode Range     : Toggle. Shows/hides the Barcode Range column in the
                           items table.
- Show Discount %        : Toggle. Shows/hides the Discount % column.
- Show Delivery Route    : Toggle. Shows/hides the Route field in Bill To.
- Show Sales Rep         : Toggle. Shows/hides the Sales Rep field.
- Show Commission        : Toggle. Shows/hides the Commission row in totals.

INPUTS — FOOTER TEXT SECTION
-----------------------------
- Footer Text            : Textarea. Text printed at the bottom of every
                           invoice (e.g., "Thank you for your business.").

INPUTS — CUSTOM HTML SECTION (collapsible)
------------------------------------------
- Use Custom HTML toggle : Enables/disables the custom HTML editor. When
                           enabled, the custom HTML completely overrides the
                           standard template in print output.
- HTML Editor            : Large textarea for raw HTML. Supports placeholder
                           variables: {{invoice_number}}, {{agent_name}},
                           {{company_name}}, {{invoice_date}}, {{items_table}},
                           {{total}}, {{total_payable}}, {{footer_text}}.

BUTTONS
-------
- Save                   : Persists all current template settings to the local
                           SQLite database. Button turns green ("Saved!") on
                           success.
- Reset                  : Shows a confirmation dialog, then restores all
                           settings to factory defaults (red/black, no logo,
                           all fields shown, default footer text).
- Import (.json)         : File picker for a previously exported template JSON
                           file. Applies its settings to the current template.
- Export (.json)         : Downloads the current template settings as a .json
                           file (logo excluded to keep file size small).
- Change Logo            : (when logo is uploaded) Re-opens the file picker to
                           replace the existing logo.
- Remove Logo            : Clears the logo; the invoice will show a building
                           icon placeholder instead.
- Load Starter           : (in HTML editor) Inserts a working starter HTML
                           template pre-styled with the current primary colour.
- Zoom Buttons (5)       : 45% / 55% / 65% / 75% / 85%. Adjusts the preview
                           zoom level using CSS zoom property.

DATA DISPLAYED
--------------
- Live A4 preview (right panel): renders the exact same design used in the
  Draft, Confirmed, and Paid invoice pages — Outfit font, red/coloured accent
  bar, logo, company details, mock agent data, 3 line items, totals section,
  signature lines, and bottom status ribbon.
- Saved/Saving status: button label changes while saving.
